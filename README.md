# 우리 부서 포털 사용법

채용 안내 포털(웹 페이지)입니다. 별도 설치 없이 `index.html` 하나로 동작합니다.

## 폴더 구성

```
project/
├─ index.html                      포털 본체 (이 파일을 열면 됩니다)
├─ README.md                       이 문서
├─ files/
│  ├─ recruitment-notice-2026-h1.pdf   채용 공고 (자료실 다운로드)
│  └─ talent-culture-guide.pdf         인재상·조직문화 소개서 (자료실 다운로드)
└─ 이전버전/
   └─ portal-v2.html               꾸미기 전 원본 사본 (보관용)
```

## 열어 보기

- `index.html`을 더블클릭하면 브라우저에서 바로 열립니다.
- 다른 사람에게 보여 주려면 `index.html`과 `files` 폴더를 **함께, 같은 위치로** 전달하세요. 폴더 구조가 달라지면 다운로드가 되지 않습니다.

## 화면 구성

상단 메뉴를 누르면 해당 영역으로 이동합니다.

| 메뉴 | 내용 |
|---|---|
| 홈 | 채용 안내 첫 화면 |
| 채용 절차 | 4단계 전형 안내 |
| 직무 소개 | 직군별 주요 업무 |
| FAQ | 자주 묻는 질문 10개 (질문을 누르면 답변이 펼쳐짐, 검색·분류 가능) |
| 자료실 | 채용 공고·인재상 소개서 PDF 다운로드 |

## 내용 수정하기

텍스트 편집기(메모장, VS Code 등)로 `index.html`을 열어 수정합니다. 수정 후 저장하고 브라우저에서 새로고침하세요.

### FAQ 추가·수정

파일 아래쪽 스크립트의 `FAQS` 목록에서 항목을 고치거나 추가합니다. 화면에는 자동으로 반영됩니다.

```js
{ cat:"지원", q:"질문 내용", a:"답변 내용" },
```

- `cat`은 `지원`, `전형`, `입사`, `조직문화` 중 하나입니다.
- 새 분류를 추가하려면 FAQ 영역의 분류 버튼(`data-cat`)도 함께 추가해야 합니다.

### 자료실 파일 교체

1. 새 PDF를 `files` 폴더에 넣습니다. 파일명은 영문 소문자와 하이픈만 사용합니다. 예: `recruitment-notice-2027-h1.pdf`
2. `index.html`의 자료실(`lib-card` 블록)에서 아래 값을 새 파일에 맞게 고칩니다. 파일을 추가하려면 블록을 복사해 붙이세요.

```html
<a class="btn btn-dl" href="files/새-파일명.pdf" download="저장될 한글 이름.pdf">다운로드</a>
```

- `href`: `files/파일명` 형태의 상대 경로 (영문 소문자·하이픈)
- `download`: 내려받을 때 저장되는 이름 (한글 가능)
- 화면의 파일명·설명·용량 글자도 함께 고쳐 주세요. 용량은 직접 적는 값이라 파일을 바꾸면 같이 바꿔야 합니다.

### 로고 넣기

로고 이미지를 `files/logo.png`로 저장하면 상단 메뉴에 자동으로 표시됩니다. 파일이 없으면 임시 마크가 보입니다.

### 색상 바꾸기

`<style>` 맨 위의 `:root { ... }` 안 색상 값만 바꾸면 전체 색이 바뀝니다. 현재는 웜 오렌지(갈색·주황 계열)입니다.

## 파일명 규칙

- 영문 소문자, 숫자, 하이픈(`-`)만 사용하고 한글과 공백은 쓰지 않습니다.
- 예: `recruitment-notice-2026-h1.pdf`

## 알아 둘 점

- 현재 포털 본문(직무 소개, 2027년 상반기 표기 등)과 자료실 PDF(2026년 상반기 공고, 다른 직무 구성)의 내용이 서로 다릅니다. 게시 전에 맞춰 주세요.
- 두 PDF는 교육용 가상 샘플 자료입니다. 실제 업무에는 사용하지 마세요.
- 푸터의 문의처(`recruit@example.com`, `02-000-0000`)는 예시입니다. 실제 연락처로 바꿔 주세요.
